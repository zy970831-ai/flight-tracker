How alerts work
  • The scheduler checks prices every 6 hours automatically
  • When any tracked price drops below your threshold, an email is sent to you
  • Make sure EMAIL_FROM, EMAIL_TO, and EMAIL_PASSWORD are set in your .env
  • Run python tracker.py in a terminal to keep the scheduler running
  • For a one-shot manual check: python tracker.py --check now
